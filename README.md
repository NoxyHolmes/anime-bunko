# 🌸 Аниме-Архив

Личный каталог просмотренных аниме-тайтлов: тиры (SSS–E), статистика с диаграммами,
календарь просмотра и настраиваемая фоновая анимация.

Сайт полностью статический, размещается на **GitHub Pages** и работает без бэкенда.
Данные хранятся в файле `data.json` в репозитории; сохранение из режима владельца
происходит через **GitHub Contents API**.

---

## 📦 Возможности

- **Тиры SSS → E** с 3D-анимированными буквами и разными яркими цветами.
- **Карточки тайтлов** — сетка (до 12 колонок), список, компактный список.
- **Drag & Drop** между тирами (мышь + тач) через SortableJS.
- **Модальное окно тайтла** с составными частями (сезоны/фильмы/спешлы), датами и временем.
- **Статистика**: жанры, тиры, общее время, время фильмов, среднее на тайтл, динамика по месяцам (Chart.js).
- **Календарь**: месячная сетка с точками и всплывающим списком + режим списка по месяцам.
- **Настройки**: 20 пресетов фоновых частиц, ползунки плотности/скорости/размера,
  тема (тёмная/светлая), акцентный цвет, вид и размер карточек, средние длительности.
- **Режим владельца** (`admin.html`): добавление/редактирование/удаление тайтлов,
  сохранение в GitHub через Personal Access Token, экспорт/импорт JSON.

## 🚀 Развёртывание на GitHub Pages

### 1. Форк / создание репозитория

Создайте публичный репозиторий, например `anime-archive`, и загрузите в него все файлы:

```
index.html
admin.html
data.json
README.md
css/styles.css
js/app.js
js/admin.js
js/particles.js
js/stats.js
```

### 2. Включение GitHub Pages

1. Откройте репозиторий → **Settings** → **Pages**.
2. В разделе **Source** выберите: `Deploy from a branch`.
3. Branch: `main`, папка: `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/anime-archive/`

### 3. Публичная и приватная ссылки

- **Публичная**: `https://ВАШ_ЛОГИН.github.io/anime-archive/index.html`
- **Для владельца**: `https://ВАШ_ЛОГИН.github.io/anime-archive/admin.html`
  > Держите ссылку на `admin.html` в тайне — она даёт доступ к редактированию.

Также поддерживается режим `index.html?mode=owner` — он подгружает `js/admin.js` динамически.

## 🔑 Создание Personal Access Token

1. Откройте https://github.com/settings/tokens
2. **Generate new token** → **Fine-grained** (или **Classic**).
   - Для **Fine-grained**: дайте доступ только к вашему репозиторию и право **Contents: Read and write**.
   - Для **Classic**: отметьте галочку `repo`.
3. Скопируйте токен (вида `ghp_…`) — он показывается только один раз.

В `admin.html`:
1. Откройте ⚙ → раздел **Данные и синхронизация**.
2. Вставьте токен, укажите `владелец/репозиторий`, ветку (`main`) и путь (`data.json`).
3. Нажмите **Сохранить на GitHub** — файл `data.json` обновится в репозитории,
   и изменения сразу появятся на публичной странице.

> 🔒 Токен сохраняется **только в localStorage вашего браузера** и отправляется исключительно на `api.github.com`.

## 🖱 Использование

### Публичный просмотр (`index.html`)
- Табы: **Архив · Статистика · Календарь · Настройки**.
- Фильтры: поиск, тир, тип, жанр, «только любимые».
- Клик по карточке → модальное окно (закрывается только крестиком или **Esc**).
- Переключение вида: сетка / список / компактный.

### Режим владельца (`admin.html`)
- Кнопка **+ Добавить тайтл** в шапке (или **Редактировать** в модалке).
- В форме: название, оригинал, тип, тир, обложка, жанры (мультиселект с поиском),
  «любимый», составные части (сезоны/фильмы/спешлы с сериями, минутами и датами).
- **Сохранить на GitHub** — PUT-запрос в Contents API с обязательным `sha`.
- Статус сохранения: «Сохранено локально» → «Отправлено на GitHub» → ошибка с описанием.
- Кнопки **Экспорт JSON** / **Импорт JSON** — ручное резервное копирование.

## 🗂 Формат data.json

```json
{
  "titles": [
    {
      "id": "t1",
      "title": "Атака титанов",
      "titleOriginal": "Shingeki no Kyojin",
      "cover": "https://…/cover.jpg",
      "type": "TV-сериал",
      "genres": ["Экшен/Боевик", "Драма"],
      "tier": "SSS",
      "favorite": true,
      "createdAt": "2024-01-15",
      "entries": [
        {
          "kind": "Сезон 1",
          "episodes": 25,
          "minutesPerEpisode": 24,
          "durationMinutes": null,
          "watchDate": "2023-11-01 – 2023-11-20"
        },
        {
          "kind": "Фильм",
          "episodes": null,
          "minutesPerEpisode": null,
          "durationMinutes": 118,
          "watchDate": "2024-01-20"
        }
      ]
    }
  ]
}
```

- `watchDate` — либо одна дата `2024-05-10`, либо период `2024-05-01 – 2024-05-20`.
- `durationMinutes` — задаётся только для фильмов (если `null`, берётся средняя длительность фильма из настроек).
- Для сериалов время = `episodes × minutesPerEpisode` (если `minutesPerEpisode` не задан — берётся среднее из настроек).

## 🧩 Технологии

- **HTML5 + CSS3 + чистый JavaScript (ES6+)** — без сборщиков.
- **Chart.js** — диаграммы статистики.
- **SortableJS** — drag & drop (мышь + тач).
- **Google Fonts** — Unbounded (заголовки) + Manrope (текст).
- **GitHub Contents API** — сохранение `data.json` из режима владельца.

---

## 💾 Локальное сохранение

Все изменения (включая настройки) автоматически сохраняются в `localStorage` с debounce 500 мс.
Если GitHub-сохранение не удалось — данные останутся в браузере, ничего не потеряется.
