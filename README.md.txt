# 🐉 Аниме-Архив

Персональный каталог просмотренных аниме с тирами, статистикой, календарём просмотра и настраиваемыми анимированными фонами. Работает полностью на клиенте, размещается на **GitHub Pages** как статический сайт.

> **Две ссылки — два режима:** публичный `index.html` для гостей (только просмотр) и приватный `admin.html` для владельца (полное редактирование + синхронизация с GitHub).

---

## 📸 Возможности

- **7 тиров** (SSS → E) с 3D-анимированными буквами и уникальными цветами
- **Drag & Drop** карточек внутри тиров и между ними (работает на тач-экранах)
- **Статистика** на Chart.js: жанры, распределение по тирам, динамика по месяцам
- **Календарь просмотра** с сеткой и списковым видом
- **20 пресетов** фоновой анимации (сакура, снег, звёзды, сердечки и др.)
- **Тёмная/светлая тема**, кастомный акцентный цвет
- **Автосохранение** в localStorage + синхронизация с GitHub через API
- **Импорт/экспорт** JSON для бэкапа
- **Полная мобильная адаптация**
